# Reference Tests

Place example test files here that demonstrate your project's testing
conventions. QualityFlow uses these as style and pattern references when
generating new tests.

Organize by test type:

```text
reference/
  tier1/          # Go / functional test examples
  tier2/          # Python / e2e test examples
```

Each reference file should be a real, working test from your project that
exemplifies the patterns QualityFlow should follow.
