# TC-E2E-001: Greenfield 3.6 serves /v1/responses from Praxis with no competing implementation

**Objective**: Verify that on a freshly installed RHOAI 3.6 cluster, `POST /v1/responses` is served
by Praxis and that no second implementation of the same path is reachable from outside the cluster.

**Preconditions**:

- Greenfield RHOAI 3.6 cluster, freshly installed — not upgraded from 3.5
- Platform Gateway deployed with Gateway API and Kuadrant/Authorino
- A valid API key or OpenShift token for an authenticated tenant
- Cluster-admin access for inspecting Service and HTTPRoute resources

**Test Steps**:

1. List every HTTPRoute in the cluster that matches the `/v1/responses` path:

   ```bash
   oc get httproute -A -o json | jq '[.items[]
     | select(.spec.rules[]?.matches[]?.path.value | test("/v1/responses"))]'
   ```

2. Confirm exactly one route matches and that its `backendRefs` resolve to the Praxis Service, not
   to an OGX Service.
3. Send an authenticated `POST /v1/responses` request through the external Gateway hostname.
4. Inspect the responding pod: correlate the request ID from the response headers against Praxis pod
   logs, and confirm no corresponding entry appears in OGX pod logs.
5. Enumerate all externally exposed Services and Routes and confirm none forwards to an OGX
   `/v1/responses` implementation.

**Expected Results**:

- Exactly one HTTPRoute matches `/v1/responses`, and its `backendRefs` name the Praxis Service
- The `POST /v1/responses` request returns HTTP 200 with a body conforming to the OpenAI Responses
  schema, containing an `id` and an `output` field
- The request is recorded in Praxis pod logs and absent from OGX pod logs
- No externally exposed Service or Route resolves to an OGX-served `/v1/responses`

**Test Data**:

```bash
curl -sS -X POST "https://${GATEWAY_HOST}/v1/responses" \
  -H "Authorization: Bearer ${TENANT_A_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{"model": "granite-3-8b-instruct", "input": "Summarize the Q3 migration report."}'
```

**Expected Response**:

```json
{
  "id": "resp_01JQ8ZK4M2R7X9",
  "object": "response",
  "model": "granite-3-8b-instruct",
  "status": "completed",
  "output": [
    {
      "type": "message",
      "role": "assistant",
      "content": [{"type": "output_text", "text": "The Q3 migration report covers ..."}]
    }
  ]
}
```
