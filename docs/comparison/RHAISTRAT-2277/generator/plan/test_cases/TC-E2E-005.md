# TC-E2E-005: RAG file_search through Praxis returns citations from pre-upgrade OGX data

**Objective**: Verify that `POST /v1/responses` with the `file_search` tool, served by Praxis and
delegated to OGX, returns citations referencing file IDs that existed before the upgrade, with valid
annotation byte offsets.

**Preconditions**:

- Cluster upgraded from 3.5 to 3.6, with Praxis fronting OGX
- A vector store created under 3.5 containing at least two attached files whose text content is
  known, so citation targets can be verified against known source text
- The pre-upgrade file IDs and the exact source text of each file recorded before the upgrade
- A question whose answer appears in exactly one of the attached files, so the expected citation
  target is unambiguous

**Test Steps**:

1. Send `POST /v1/responses` with the `file_search` tool enabled and the vector store ID from the
   preconditions, asking the prepared question.
2. Parse the response for annotation objects of type `file_citation`.
3. For each citation, extract the referenced `file_id`.
4. For each annotation, extract `start_index` and `end_index` and slice the response output text at
   those offsets.
5. Confirm the delegation actually occurred by locating the corresponding retrieval call in OGX pod
   logs on port 8321.

**Expected Results**:

- The request returns HTTP 200 with at least one annotation of type `file_citation`
- Every cited `file_id` is one of the file IDs recorded before the upgrade — no citation references
  an ID created after the upgrade
- The expected file, the one containing the answer, appears among the cited file IDs
- For every annotation, `0 <= start_index < end_index <= len(output_text)`, and slicing the output
  text at those offsets yields a non-empty span
- OGX pod logs show a retrieval call received on port 8321 correlated to this request

**Test Data**:

```bash
curl -sS -X POST "https://${GATEWAY_HOST}/v1/responses" \
  -H "Authorization: Bearer ${TENANT_A_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
        "model": "granite-3-8b-instruct",
        "input": "What retention period does the archival policy specify?",
        "tools": [{"type": "file_search", "vector_store_ids": ["vs_01HQ7RM3P8"]}]
      }'
```
