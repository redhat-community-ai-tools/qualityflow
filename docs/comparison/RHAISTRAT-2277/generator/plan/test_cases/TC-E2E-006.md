# TC-E2E-006: Rollback reverts external routing to OGX within five minutes with state intact

**Objective**: Verify that an administrator can revert external routing from Praxis back to OGX
during the transition window, that `POST /v1/responses` succeeds through OGX within five minutes of
initiating rollback, and that no state is lost.

**Preconditions**:

- Cluster upgraded from 3.5 to 3.6, currently routing external traffic to Praxis
- Cluster-admin able to edit the DataScienceCluster or OGXServer CR and the Gateway HTTPRoutes
- A state inventory captured immediately before rollback: counts of files, vector stores,
  conversations, and responses, plus a sample of IDs from each

**Test Steps**:

1. Capture the pre-rollback state inventory and record the wall-clock time as T0.
2. Trigger the documented rollback procedure. The concrete mechanism is not yet defined in the
   strategy, which proposes a flag on the DataScienceCluster CR or the OGXServer CR as a
   possibility — use whichever mechanism the implementation ships, and record which one was used.
3. Poll `POST /v1/responses` against the unchanged external hostname every 15 seconds, recording the
   timestamp of the first HTTP 200.
4. Once the first success is observed, correlate its request ID against OGX pod logs to confirm OGX,
   not Praxis, served it.
5. Re-run the state inventory from step 1 and compare against the pre-rollback capture.
6. Retrieve each sampled ID through the rolled-back endpoint.

**Expected Results**:

- The first successful `POST /v1/responses` after rollback occurs no more than five minutes after T0
- That request appears in OGX pod logs and not in Praxis pod logs
- Post-rollback counts for files, vector stores, conversations, and responses equal the pre-rollback
  counts
- Every sampled ID resolves with HTTP 200 after rollback and returns the same content as before
- The external hostname is unchanged throughout — the client makes no configuration change

**Validation**:

- `oc get httproute -A -o json | jq '[.items[].spec.rules[]?.backendRefs[]?.name] | unique'` shows
  the OGX Service and no longer the Praxis Service for the migrated paths
