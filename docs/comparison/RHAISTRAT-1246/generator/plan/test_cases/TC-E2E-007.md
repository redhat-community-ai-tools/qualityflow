# TC-E2E-007: Tool calling via responses API

**Objective**: Verify that tool calling works correctly with the
`remote::anthropic` provider through the responses API.

**Preconditions**:

- RHOAI 3.5 cluster with `remote::anthropic` provider activated

**Test Steps**:

1. Send a request to the responses API with a tool definition
   (same tool as TC-E2E-006 but through the responses endpoint)
2. Verify the response contains a tool call invocation
3. Submit the tool result back and verify the model produces a
   final response incorporating it

**Expected Results**:

- HTTP 200 response with tool call information in the response body
- Tool call contains the correct function name and arguments
- Follow-up response incorporating tool result returns HTTP 200
