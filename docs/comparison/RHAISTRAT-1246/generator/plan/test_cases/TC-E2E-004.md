# TC-E2E-004: Anthropic model listing via /v1/models

**Objective**: Verify that the `/v1/models` endpoint returns Anthropic
models in the correct AsyncAnthropic SDK format when the provider is
configured.

**Preconditions**:

- RHOAI 3.5 cluster with `remote::anthropic` provider activated

**Test Steps**:

1. Query the model listing endpoint:

   ```bash
   curl -s <ogx-route>/v1/models | jq .
   ```

2. Verify the response includes Anthropic model entries
3. Verify the response format matches the AsyncAnthropic SDK
   structure (not the OpenAI format)
4. Confirm model IDs correspond to known Anthropic Claude models

**Expected Results**:

- HTTP 200 response containing a JSON array or object with model
  entries
- At least one model entry with an Anthropic model identifier
- Model listing format differs from OpenAI's `/v1/models` response
  structure (Anthropic uses a different schema)
