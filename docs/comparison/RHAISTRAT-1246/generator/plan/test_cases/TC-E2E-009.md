# TC-E2E-009: Provider activation via ANTHROPIC_API_KEY env var

**Objective**: Verify that the `remote::anthropic` provider is
conditionally activated only when the `ANTHROPIC_API_KEY` environment
variable is set, following the `${env.ANTHROPIC_API_KEY:+anthropic-inference}`
activation pattern.

**Preconditions**:

- RHOAI 3.5 cluster with OGX K8s Operator installed
- OGX distribution config includes the conditional activation
  pattern for the Anthropic provider

**Test Steps**:

1. Deploy the OGX distribution with `ANTHROPIC_API_KEY` set in
   the user's ConfigMap or CR spec
2. Verify the Anthropic provider is listed in `/v1/providers`
3. Verify inference requests to Claude models succeed (HTTP 200)
4. Redeploy the OGX distribution without `ANTHROPIC_API_KEY`
5. Verify the Anthropic provider is NOT listed in `/v1/providers`

**Expected Results**:

- With `ANTHROPIC_API_KEY` set: provider appears in `/v1/providers`
  and inference succeeds
- Without `ANTHROPIC_API_KEY`: provider does not appear in
  `/v1/providers`
- The activation pattern mirrors how other providers (Bedrock,
  WatsonX, Azure, OpenAI) are configured
