# TC-E2E-006: Tool calling via chat completions API

**Objective**: Verify that tool calling works correctly with the
`remote::anthropic` provider through the chat completions API.

**Preconditions**:

- RHOAI 3.5 cluster with `remote::anthropic` provider activated

**Test Steps**:

1. Send a chat completion request with a tool definition:

   ```bash
   curl -s -X POST <ogx-route>/v1/chat/completions \
     -H "Content-Type: application/json" \
     -d '{
       "model": "<anthropic-model-id>",
       "messages": [{"role": "user", "content": "What is the weather in London?"}],
       "tools": [{
         "type": "function",
         "function": {
           "name": "get_weather",
           "description": "Get the current weather for a location",
           "parameters": {
             "type": "object",
             "properties": {
               "location": {"type": "string", "description": "City name"}
             },
             "required": ["location"]
           }
         }
       }]
     }'
   ```

2. Verify the response contains a tool call with the correct
   function name and arguments
3. Send a follow-up message with the tool result and verify the
   model incorporates it into a final response

**Expected Results**:

- HTTP 200 response with `tool_calls` array in the assistant message
- Tool call contains `function.name` = `get_weather` and
  `function.arguments` includes `location`
- Follow-up response incorporating the tool result returns HTTP 200
  with a coherent completion
