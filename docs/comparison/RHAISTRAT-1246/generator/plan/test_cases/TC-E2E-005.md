# TC-E2E-005: Provider listing includes remote::anthropic

**Objective**: Verify that the `remote::anthropic` provider appears
in the `/v1/providers` endpoint output on a deployed OGX distribution.

**Preconditions**:

- RHOAI 3.5 cluster with `remote::anthropic` provider activated

**Test Steps**:

1. Query the provider listing endpoint:

   ```bash
   curl -s <ogx-route>/v1/providers | jq .
   ```

2. Verify the response includes an entry for `remote::anthropic`
3. Verify the provider entry contains the expected metadata (type,
   status, or configuration reference)

**Expected Results**:

- HTTP 200 response with a JSON body listing all configured providers
- The list contains an entry with provider type `remote::anthropic`
- The provider entry indicates an active/configured status
