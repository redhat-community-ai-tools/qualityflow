# TC-E2E-008: MCP server integration with Anthropic models

**Objective**: Verify that MCP servers work correctly with Anthropic
models through the `remote::anthropic` provider.

**Preconditions**:

- RHOAI 3.5 cluster with `remote::anthropic` provider activated
- An MCP server configured and accessible from the OGX distribution

**Test Steps**:

1. Configure an MCP server in the OGX distribution that is
   compatible with Anthropic models
2. Send an inference request that triggers MCP server interaction
3. Verify the request completes successfully and the MCP server
   was invoked as part of the inference flow

**Expected Results**:

- Inference request returns HTTP 200 with a valid response
- MCP server logs show it was invoked during the request
- Response content reflects MCP server tool/resource usage
