# TC-E2E-002: Streaming chat completion with temperature parameters

**Objective**: Verify that the `remote::anthropic` provider supports
streaming responses and temperature/sampling parameters for chat
completions.

**Preconditions**:

- RHOAI 3.5 cluster with `remote::anthropic` provider activated
- Valid `ANTHROPIC_API_KEY` configured

**Test Steps**:

1. Send a streaming chat completion request:

   ```bash
   curl -s -N -X POST <ogx-route>/v1/chat/completions \
     -H "Content-Type: application/json" \
     -d '{
       "model": "<anthropic-model-id>",
       "messages": [{"role": "user", "content": "Count from 1 to 5"}],
       "stream": true,
       "temperature": 0.7
     }'
   ```

2. Verify that the response is delivered as server-sent events (SSE)
3. Verify that each SSE chunk contains valid JSON with incremental
   completion content
4. Send a second request with `temperature: 0.0` and confirm the
   response is deterministic (repeat twice, compare outputs)

**Expected Results**:

- Streaming response returns `Content-Type: text/event-stream`
- Each chunk follows SSE format (`data: {...}`)
- Final chunk contains `finish_reason` field
- Low-temperature request produces consistent output across
  repeated calls

**Test Data**:

```json
{
  "model": "<anthropic-model-id>",
  "messages": [{"role": "user", "content": "Count from 1 to 5"}],
  "stream": true,
  "temperature": 0.7
}
```
