# TC-E2E-001: Deploy vLLM-Omni with Qwen3-Omni-30B-A3B and validate end-to-end TTS workflow

**Objective**: Validate the complete user journey from ServingRuntime annotation
verification through InferenceService deployment with Qwen3-Omni-30B-A3B (all 3 init
stages) to successful TTS inference on the vLLM-Omni runtime.

**Preconditions**:

- RHOAI operator is installed with vLLM-Omni ServingRuntime template
- Qwen3-Omni-30B-A3B weights in S3 models bucket (~86 GB; downloaded by KServe
  storage initializer at pod startup; this model exercises all 3 initialization
  stages: LLM, TTS, Code2Wav — as AC-2 requires)
- GPU node with 2x GPUs (reference: NVIDIA H100 80GB) is available
- `HF_HOME=/tmp/hf_home` is set in the container environment
- openshift-python-wrapper is available in the test environment

**Test Steps**:

1. Via `ServingRuntime.get()`, confirm the vLLM-Omni ServingRuntime exists and
   the `opendatahub.io/dashboard: "true"` annotation is present.
2. Via `create_isvc()`, create an InferenceService with:
   - Runtime: vLLM-Omni
   - Model: Qwen3-Omni-30B-A3B (from S3 models bucket, ~86 GB)
   - Hardware profile: 2x NVIDIA GPU
   - Environment: `HF_HOME=/tmp/hf_home`
3. Via `pod_is_ready()`, wait for the predictor pod to reach Ready state (all 3
   initialization stages — LLM, TTS, Code2Wav — must complete before `/health`
   returns 200; timeout: 900 seconds).
4. Via `OpenAIClient.get("/health")`, assert response status code == 200.
5. Via `OpenAIClient.get("/v1/models")`, assert the response contains
   `Qwen3-Omni-30B-A3B` in the model list.
6. Via `OpenAIClient.post("/v1/audio/speech")` with model `Qwen3-Omni-30B-A3B`,
   assert response status code == 200 and the response body is non-empty.
7. Assert the response content-type indicates audio format.

**Expected Results**:

- ServingRuntime exists with required dashboard annotation
- InferenceService transitions to Ready state after all 3 initialization stages
  complete (LLM, TTS, Code2Wav)
- `/health` returns HTTP 200 post-initialization
- `/v1/models` returns `Qwen3-Omni-30B-A3B` in the model list
- `/v1/audio/speech` returns HTTP 200 with a non-empty, valid audio response
- The entire workflow from annotation check through inference completes without
  errors

**Notes**: Step 5 (`/v1/models` validation) also confirms that the
`--served-model-name={{.Name}}` template variable resolved correctly at deployment
time.
