# TC-E2E-001: End-to-end metrics pipeline validation

**Objective**: Validate the full observability pipeline from auth
traffic generation through metric scraping, recording rule
computation, and dashboard panel rendering.

**Preconditions**:

- RHOAI 3.6-ea1 on OpenShift 4.16+
- At least one LLMInferenceService or MaaS model deployed
- ServiceMonitor, PrometheusRule, and Perses dashboard applied
- No prior auth traffic (clean state)

**Test Steps**:

1. Verify `auth_server_authconfig_response_status` is NOT present
   in Prometheus (metrics are lazy-initialized):

   ```bash
   curl -s "https://<prometheus-route>/api/v1/query?query=\
     auth_server_authconfig_response_status" | \
     jq '.data.result | length'
   ```

   Expected: 0
2. Generate mixed auth traffic for 6 minutes (80% OK, 20%
   denied):

   ```bash
   for i in $(seq 1 360); do
     if [ $((i % 5)) -eq 0 ]; then
       # Invalid request (denied)
       grpcurl -plaintext -d '{"attributes": {"request": \
         {"http": {"method": "GET", "path": "/invalid"}}}}' \
         <authorino-service>:50051 \
         envoy.service.auth.v3.Authorization/Check
     else
       # Valid request (allowed)
       grpcurl -plaintext -d '{"attributes": {"request": \
         {"http": {"method": "GET", "path": "/test"}}}}' \
         <authorino-service>:50051 \
         envoy.service.auth.v3.Authorization/Check
     fi
     sleep 1
   done
   ```

3. Verify raw metrics appear in Prometheus:

   ```bash
   curl -s "https://<prometheus-route>/api/v1/query?query=\
     auth_server_authconfig_response_status" | \
     jq '.data.result | length'
   ```

   Expected: > 0
4. Verify recording rules compute:

   ```bash
   curl -s "https://<prometheus-route>/api/v1/query?query=\
     maas:auth_decisions:rate5m" | jq '.data.result[0].value[1]'
   curl -s "https://<prometheus-route>/api/v1/query?query=\
     maas:auth_deny_ratio:rate5m" | jq '.data.result[0].value[1]'
   curl -s "https://<prometheus-route>/api/v1/query?query=\
     maas:auth_latency_p95:5m" | jq '.data.result[0].value[1]'
   ```

5. Verify dashboard stat panels show non-zero values:

   ```bash
   curl -s "https://<prometheus-route>/api/v1/query?query=\
     sum(maas:auth_decisions:rate5m) or vector(0)" | \
     jq '.data.result[0].value[1]'
   ```

6. Verify deny ratio is approximately 0.20.

**Expected Results**:

- Metrics are absent before traffic (lazy initialization
  confirmed)
- Raw metrics appear after first auth traffic
- `maas:auth_decisions:rate5m` shows positive rate values
- `maas:auth_deny_ratio:rate5m` shows approximately 0.20
- `maas:auth_latency_p95:5m` shows positive latency values
- Dashboard stat panels display non-zero, non-error values
- Full pipeline from Authorino → Prometheus → recording rules →
  dashboard is functional
