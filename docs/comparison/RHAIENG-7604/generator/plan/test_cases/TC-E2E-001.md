# TC-E2E-001: Direct source mappings and fixed ownership issuer

**Objective**: Verify that populated source ownership fields map directly to Praxis target
rows and that every migrated row receives the fixed ownership issuer.

**Preconditions**:

- A cluster-admin test identity can invoke the migration CLI or Job and inspect both source
  and target datastores.
- The supported CLI executable, command or subcommand, target-row query method, and fixture
  schema have been confirmed for the test environment.
- The same fixture and assertions are executed against the selected pre-upgrade and
  post-upgrade deployments; exact versions remain an open plan gap.
- The target datastore is isolated from prior runs, or the fixture rows have unique identifiers
  that allow their migrated rows to be selected without including unrelated data.

**Test Steps**:

1. Create at least two source rows using the supported fixture mechanism. Give each row a
   present, non-empty `tenant_id` and `owner_principal`.
2. Record the source values and confirm that no fallback flags are supplied for this run.
3. Run the supported OGX DB migration CLI command or Job and wait for its completion signal.
4. Collect the command or Job result and migration output, then inspect the Praxis target rows
   corresponding to the source fixture.
5. Compare each target row with its source row for `tenant_id` and `owner_subject`, and inspect
   `owner_issuer` on every migrated target row.

**Expected Results**:

- The migration command or Job reports successful completion.
- Each target row's `tenant_id` exactly equals the corresponding source row's non-empty
  `tenant_id`.
- Each target row's `owner_subject` exactly equals the corresponding source row's
  `owner_principal`.
- Every migrated target row has `owner_issuer` equal to
  `urn:rhoai:ogx:production`.

**Test Data**:

```yaml
rows:
  - fixture_label: direct-finance-row
    tenant_id: tenant-finance-01
    owner_principal: principal-finance-01
  - fixture_label: direct-research-row
    tenant_id: tenant-research-02
    owner_principal: principal-research-02
owner_issuer: urn:rhoai:ogx:production
```

Map these logical fields to the supported source-fixture schema once the fixture contract is
confirmed.

**Validation**:

- Use the supported target-datastore inspection method to select only rows created from the
  fixture and verify all `tenant_id`, `owner_subject`, and `owner_issuer` values.
