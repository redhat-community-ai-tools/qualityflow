CI Integration Setup

Add this step to your test repo's CI pipeline to upload coverage to QualityFlow after each test run. Coverage delta is tracked per-PR.

GitHub Actions

- name: Upload coverage to QualityFlow
  run: |
    SOURCE_SHA=$(git -C source-repo rev-parse HEAD)
    curl -X POST \
      -H "Content-Type: application/json" \
      -H "X-API-Key: ${{ secrets.QUALITYFLOW_API_KEY }}" \
      -d "{
        \"project\": \"example\",
        \"source_repo\": \"my-org/my-project\",
        \"source_commit\": \"$SOURCE_SHA\",
        \"source_branch\": \"main\",
        \"test_repo\": \"${{ github.repository }}\",
        \"test_pr\": ${{ github.event.pull_request.number }},
        \"format\": \"auto\",
        \"data\": \"$(base64 -w0 coverage.out)\",
        \"post_pr_comment\": true,
        \"create_check_run\": true
      }" \
      $QUALITYFLOW_URL/api/coverage/test/upload

Tekton Task

- name: upload-coverage
  image: alpine/curl:latest
  script: |
    curl -X POST \
      -H "Content-Type: application/json" \
      -H "X-API-Key: $(params.QUALITYFLOW_API_KEY)" \
      -d "{
        \"project\": \"$(params.PROJECT)\",
        \"source_repo\": \"$(params.SOURCE_REPO)\",
        \"source_commit\": \"$(params.SOURCE_COMMIT)\",
        \"test_repo\": \"$(params.TEST_REPO)\",
        \"format\": \"auto\",
        \"data\": \"$(base64 -w0 /workspace/coverage.out)\"
      }" \
      $(params.DASHBOARD_URL)/api/coverage/test/upload

curl (manual test)

curl -X POST \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_KEY" \
  -d @- https://DASHBOARD/api/coverage/test/upload <<EOF
{
  "project": "example",
  "source_repo": "my-org/my-project",
  "source_commit": "abc1234def5678",
  "test_repo": "my-org/my-tests",
  "test_pr": 1234,
  "format": "auto",
  "data": "$(base64 -w0 coverage.out)",
  "post_pr_comment": true,
  "create_check_run": true
}
EOF

How it works

  • • Your test CI runs tests against the product repo and generates a coverage file
  • • Upload the coverage file with the product repo's commit SHA
  • • QualityFlow compares against the merge-base and computes delta + patch coverage
  • • With create_check_run, uncovered lines appear as annotations in PR diffs
  • • Optionally posts a PR comment showing the coverage impact
  • • Tracks which test PRs moved the coverage needle over time
