# Plugin evals

`claude plugin eval` suite for QualityFlow. Cases 01–08 cover whole flows (`/review-stp`,
`/std-builder`, `/review-std`); cases 10–27 cover one skill each.
Each case runs with the plugin and without it; `Δ` is what QualityFlow adds.

| Case | Expected | What it catches |
|:--|:--|:--|
| `01-cdrom-hotplug` | `NEEDS_REVISION`, 1–2 critical | Rule A leaks ("reconcile" in a Testing Goal, "VM controller" in a scenario) that a March run missed |
| `02-nad-72329` | `NEEDS_REVISION`, 2–4 critical | A well-written STP in the wrong structure (no Section I / IV) |
| `03-degraded` | `NEEDS_REVISION`, 2–6 critical | Five planted defects: Rule A ×2, Rule C, Dimension 2 coverage gap, Rule J |
| `04-neg-std-review` | reviewer does not fire | An STD review request must not trigger the STP reviewer |
| `05-std-cdrom-hotplug` | STD YAML + pytest stubs | All 47 STP rows become scenarios; stubs carry Preconditions / Steps / Expected |
| `06-std-missing-stp` | refuses | No STP on disk: must point to `/stp-builder`, not invent an STD |
| `07-std-review-clean` | no traceability findings | A complete STD must not be flagged for gaps, orphans or missing PSE |
| `08-std-review-degraded` | `NEEDS_REVISION`, 3–6 critical | Three planted criticals: an STP row with no scenario, an orphan scenario, a stub with no docstring |

Cases 01–03 are real, sanitized pipeline STPs from the `eval/stp-reviewer-exemplars` branch. Cases 05–08 reuse the
CNV-68916 STP; the STD in 07 was generated by QualityFlow from it, and 08 is that STD with the three defects applied.

## Run

```bash
GOOGLE_APPLICATION_CREDENTIALS="$HOME/.config/gcloud/application_default_credentials.json" \
  claude plugin eval . -j 8 --scaffold --no-publish --judge-model sonnet --allow-tools Write Edit
```

- `--scaffold` is required: each case's `fixture.sh` seeds the run's working directory (inputs, project
  config, pipeline state). `context.add_dirs` does not reach the agent in the current build.
- On Vertex, pin `GOOGLE_APPLICATION_CREDENTIALS`: runs get a throwaway `$HOME`, so the
  default ADC path is not found.
- `--judge-model sonnet`: the default judge may resolve to a model your Vertex project lacks.
- `--allow-tools Write Edit`: cases 05–08 write the STD and review files. Bash is not granted:
  the eval sandbox refuses Bash on a machine whose `~/.docker` holds symlinks, and the
  flows complete without the pipeline-state script.
- Regex `count:N` graders ignore the `m` flag, so anchor on `\n`, not `^`.

A full run is 48 agent runs, about 30 minutes and $50 at list price; `05` alone is ~$20.
